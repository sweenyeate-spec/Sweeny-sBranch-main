ORACLE OF SHRIMP, ABOUT:

Goals for the Oracle of Shrimp


We want to learn how to use Bootstrap, HTML, CSS, JavaScript, and PHP to create an interactive website which will store user data related to fortunes from the shrimp oracle via a database.

Our basic goal is to create a database and use it to store user data like fortunes, login credentials, and some sort of statistics related to fortunes. We want to create a somewhat minimalistic website to achieve this which will have a relatively simple navbar and login page. And of course our clickable fortune teller shrimp, whom we have not yet named.

Extended/Stretched Goals

We also have extra goals to reach assuming we have the time and/or capacity to do so. We thought of adding evil fortunes as a possibility and we would like to add skins and items to the oracle which could also be extended into our database that way users can customize more. If possible we also wanted to add a 3d model for the oracle just to make it more interesting.
